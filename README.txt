БАРСИК КЛИКЕР — САЙТ

Файлы:
- index.html — сайт с игрой, работающей прямо в браузере.
- barsikclicker.apk — Android-приложение для скачивания с сайта.

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в современном браузере (Chrome, Safari, Firefox или Edge).
3. Для публикации в интернете загрузите index.html и barsikclicker.apk в одну папку на веб-хостинге.

Важно:
- Ссылка на APK работает, когда оба файла лежат рядом.
- Игровой прогресс сохраняется в локальном хранилище браузера на этом устройстве.
- Для собственного домена barsikclicker.com нужно отдельно настроить домен и хостинг.
